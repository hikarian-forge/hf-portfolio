# Author Template

Use this template as a reference for creating author profiles.

## Required Fields

- **name** - The name of the author (e.g., "John Doe")
- **bio** - A short bio of the author, something short and simple
- **avatar** - A URL to the author's avatar image
- **socials** - Twitter handle, GitHub username, LinkedIn profile URL
- **status** - Can be "active" or "inactive"
